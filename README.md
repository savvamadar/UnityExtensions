# UnityExtensions
Scripts that add useful functionality to unity

Vector3Extensions:
- InverseLerp | Like Mathf.InverseLerp but for Vector3
- RelativeLocalPosition | Gets the position of Transform "child" relative to Transform "parent"
- Ceil | All components are rounded up to an integer greater than or equal to that component
- Floor | All components are rounded down to an integer less than or equal to that component
- Round | All components are rounded to the nearest integer for that component
- SerializableVector3 | A class that makes Vector3 serializable

QuaternionExtensions:
- InverseLerp | Like Mathf.InverseLerp but for Quaternions
- Difference | Gets the difference between Quaternions
- Add | Gets the result of the addition of two quaternions
- RelativeLocalRotation | Gets the rotation of Transform "child" relative to Transform "parent"
- SerializableQuaternion | A class that makes Quaternions serializable

GameObjectExtensions:
- SetLayerRecursive | Sets the layer for the GameObject and all it's children
- GetOrAddComponent | Gets, and if it's missing also adds, the component on a GameObject
- PositionRotation | Sets the World Space position and World Space rotation of a GameObject
- LocalPositionRotation | Sets the Local Space position and Local Space rotation of a GameObject

TransformExtensions:
- SetLayerRecursive | Sets the layer for the Transform and all it's children
- GetOrAddComponent | Gets, and if it's missing also adds, the component on a Transform
- PositionRotation | Sets the World Space position and World Space rotation of a Transform
- LocalPositionRotation | Sets the Local Space position and Local Space rotation of a Transform

MaterialExtensions:
- NonInstancedName | Returns the material name that doesn't end with " (Instance)"
- IsInstanced | Returns true if the material name ends with " (Instance)"

NavMeshExtensions:
- GetNavMeshData | Editor only - Returns the baked NavMeshData.asset file for the current scene or a specified scene
- GetOffMeshLinks | Editor only - Returns a list of OffMeshLinks auto generated by Unity -- may not work with new NavMesh implementation
- GetNavMeshAgentRadius | Editor only - Returns the baked NavMeshData's agent radius
- GetGeneratedOffMeshDropHeight | Editor only - Returns the baked NavMeshData's off mesh drop height
- GetGeneratedOffMeshJumpHeight | Editor only - Returns the baked NavMeshData's off mesh jump height
- GetInnerEdgePoints | Editor only - Returns a list of World Space positions that represent an estimate of the NavMesh's inner edge points
- CalculateEdges | Editor only - Returns a list of World Space positions that represent an estimate of the NavMesh's edges
- GetBounds | Returns an array of World Space positions that represent the rough NavMesh bounds
- GetCenter | Returns a World Space position in the center of the NavMesh bounds/ provided bounds
- GetDimensions | Returns the bounding box dimensions of the NavMesh bounds/ provided bounds
- GetSingleMesh | Returns NavMesh as one large Mesh
- GetMultiMesh | Returns an array of Meshes represeting all submeshes of the NavMesh
